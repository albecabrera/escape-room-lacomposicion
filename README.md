## Descripción

Escape room literario con sistema de 3 niveles y 15 salas en total. Los alumnos resuelven enigmas basados en la trama, los personajes y los temas del cuento para avanzar.

- **Nivel 1** — Introducción al relato
- **Nivel 2** — Conflicto y tensión
- **Nivel 3** — Desenlace y reflexión

Las hojas de respuestas para el docente están protegidas por contraseña.
